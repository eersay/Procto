# Copyright filing materials

Prepared for registering Procto's source code as a **Literary Work** under
Section 2(o) of the Copyright Act, 1957 (computer programme), per Rule 70(5)
of the Copyright Rules, 2013.

## Files

- **`source-code-printout.txt`**: the full, paginated source code (about
  200 pages at about 55 lines per page), generated from
  `backend/prisma/schema.prisma`, `backend/src/**/*.ts`, and
  `frontend/src/**/*.ts(x)` as they stood on the date this was generated.
  Keep this as your reference copy of exactly what was submitted.
- **`source-code-excerpt-for-filing.pdf`**: the actual submission document,
  ready to print. Contains the first 10 and last 10 pages only, per the
  standard convention for long source-code submissions, with a signature
  line and page number on every page.
- **`source-code-excerpt-for-filing.txt`**: the plain-text version of the
  same excerpt, kept as a reference in case you need to regenerate or edit
  the PDF.
- **`statement-of-particulars-draft.md`**: a draft of Form XIV's Statement
  of Particulars, pre-filled with everything known from the codebase.
  Fields only you can supply (legal name, address, nationality, ID proof)
  are left as `[ ... ]` placeholders.

## Before printing

1. Confirm the source snapshot in these files still matches what you intend
   to register. If you make further code changes, regenerate them.
2. Sign each printed page as the applicant, per the Copyright Office
   checklist (a blank signature line is already printed at the bottom of
   every page).
3. File via **ipindia.gov.in** (copyright.gov.in was being retired around
   31 July 2026, so verify it's not already gone before you start).

## Not included here

- The actual Form XIV / SoP / SoFP PDF forms. Download those from the
  Copyright Office site itself; this draft is content to transcribe into
  them, not a substitute for the official forms.
- Proof of identity/address, Power of Attorney (if filing through an
  advocate), or the processing fee. All of that is handled directly on
  the portal.
