# Copyright filing materials

Prepared for registering Procto's source code as a **Literary Work** under
Section 2(o) of the Copyright Act, 1957 (computer programme), per Rule 70(5)
of the Copyright Rules, 2013.

## Files

- **`source-code-printout.txt`** — the full, paginated source code (~200
  pages at ~55 lines/page), generated from `backend/prisma/schema.prisma`,
  `backend/src/**/*.ts`, and `frontend/src/**/*.ts(x)` as they stood on the
  date this was generated. Keep this as your reference copy of exactly what
  was submitted.
- **`source-code-excerpt-for-filing.txt`** — the actual submission excerpt:
  the first 10 and last 10 pages only, per the standard convention for long
  source-code submissions. **Print this one.**
- **`statement-of-particulars-draft.md`** — a draft of Form XIV's Statement
  of Particulars, pre-filled with everything known from the codebase.
  Fields only you can supply (legal name, address, nationality, ID proof)
  are left as `[ ... ]` placeholders.

## Before printing

1. Confirm the source snapshot in these files still matches what you intend
   to register — if you make further code changes, regenerate them.
2. Each printed page should be signed by you as the applicant, per the
   Copyright Office checklist.
3. File via **ipindia.gov.in** (copyright.gov.in was being retired around
   31 July 2026 — verify it's not already gone before you start).

## Not included here

- The actual Form XIV / SoP / SoFP PDF forms — download those from the
  Copyright Office site itself; this draft is content to transcribe into
  them, not a substitute for the official forms.
- Proof of identity/address, Power of Attorney (if filing through an
  advocate), or the processing fee — all handled directly on the portal.
