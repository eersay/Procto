## Supporting notes for the application

- **Sole authorship**. Git history for the project shows a single author
  across all commits (`Bhagyasree Roy`), which supports the Col. 7 claim
  and means no NOC (No Objection Certificate) from a co-author is needed.
- **AI-assisted development**. Parts of the code were written with AI
  assistance (Claude Code), under the applicant's direction, review, and
  integration decisions throughout. Section 2(d)(vi) of the Copyright Act
  defines the author of a computer-generated work as the person who
  causes the work to be created. The applicant directed the AI, made all
  architectural and feature decisions, and reviewed and integrated the
  output. The SoP form has no dedicated field for this today, but keep
  this reasoning and the git commit history on hand in case it comes up
  during examination.
- **Source code submission**. See `source-code-excerpt-for-filing.pdf` in
  this same folder: the first 10 and last 10 pages of the paginated
  source, ready to print and sign per Rule 70(5).
- **Fee and mode of filing**. Pay via the portal's payment gateway. Check
  the current fee schedule on the Copyright Office / IPINDIA site at
  filing time, since amounts change.
