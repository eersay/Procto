# Screenshots

Drop these four files here (exact names — the root README references them
directly):

- `landing.png` — the landing page (`/`)
- `login.png` — the login page (`/login`), Student tab
- `student-dashboard.png` — `StudentDashboard`, signed in as a student with data
- `faculty-dashboard.png` — `FacultyDashboard`, signed in as faculty with data

Run `make seed` (or `npx prisma db seed` in `backend/`) first so these show
real courses/exams/results instead of empty states. Seeded demo logins are in
the root README.
